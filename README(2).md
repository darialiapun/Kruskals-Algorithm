# Алгоритм Краскала (MST)

Домашнее задание: поиск минимального остовного дерева алгоритмом Краскала на Python.

## Что такое минимальное остовное дерево

Остовное дерево — это набор рёбер, который соединяет все вершины графа и не содержит циклов. В нём всегда ровно V − 1 ребро. Минимальное остовное дерево — то из них, у которого сумма весов наименьшая.

Пример: граф из 6 вершин и 9 рёбер. Его минимальный остов весит 13:

```
A --2-- C --1-- B --5-- D --2-- E --3-- F
```

Краскал сортирует рёбра по весу и берёт их от лёгких к тяжёлым, пропуская те, что образуют цикл. Сложность O(E log E): основное время уходит на сортировку.

## Что реализовано

| Функция | Что делает |
|---|---|
| `build_graph` | строит граф как словарь смежности `{v: [(u, w), ...]}` |
| `DSU.find` | находит корень компоненты, со сжатием путей |
| `DSU.union` | объединяет компоненты по рангу; возвращает `False`, если ребро даст цикл |
| `kruskal_mst` | возвращает рёбра остова и их суммарный вес |
| `count_components` | считает число связных компонент графа |
| `has_cycle` | проверяет набор рёбер на циклы |
| `is_spanning_forest` | проверяет остов: рёбра из графа, нет циклов, все вершины связаны |
| `brute_force_mst_weight` | эталонный вес остова полным перебором (для тестов) |
| `prim_weight` | вес остова алгоритмом Прима (для сверки) |

## Особые случаи

- Несвязный граф: строится минимальный остовный лес, по дереву на каждую компоненту.
- Одинаковые веса: остов не единственный, проверяются вес и корректность структуры.
- Петли не берутся никогда, из кратных рёбер берётся самое лёгкое.
- Отрицательные веса допустимы: алгоритму важен только порядок весов.

## Запуск

Весь код находится в одной ячейке ноутбука `Алгоритм_Краскала.ipynb`. Откройте его в Jupyter или Google Colab и запустите ячейку.
